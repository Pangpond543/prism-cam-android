# Prism Cam Android — architecture

## Folders
- `app/src/main/java/com/prism/cam/`
  - `MainActivity.kt` — single activity; never recreated on rotate/resize (manifest `configChanges`); test hook `act` extra.
  - `PrismLog.kt` — local log `/sdcard/Android/data/com.prism.cam/files/prism.log` + logcat tag `PrismCam`; `START ver=…` line per start.
  - `prefs/CamPrefs.kt` — remembered camera choices (timer, shape, grid, smooth, left-handed).
  - `prefs/PrismPrefs.kt` — shell settings `prism.lang / prism.theme / prism.look` (SharedPreferences, read once, Compose state).
  - `i18n/` — `T("ไทย")` + `En.kt` map (Thai source, English keyed by Thai).
  - `ui/theme/PrismTheme.kt` — tokens from the desktop CSS: `prismColors(dark, look)`, `Prism` (gradient, brand teal, easing, AUTHOR/MODEL), `PrismFont`, type scale.
  - `ui/kit/` — the Prism component kit:
    `prismPane` / `PrismPanel` (glass pane or classic panel) · `PrismText` · `PrismWordmark` (+ by 543) · `PrismPill` (primary / secondary / warn) ·
    `PrismSegmented` (sliding gradient thumb) · `PrismChip` · `PrismToast` · `PrismLogo` (teal mark, swings in Glass) ·
    `PrismBackground` (Classic page colour / Glass AGSL gradient on Android 13+, static gradient below) ·
    camera controls `CamShutter`, `CamRoundButton`, `CamZoomPills` · `PrismIcon` (suite line icons; `PrismIconData.kt` is generated by `tools/icons-to-kotlin.mjs`).
  - `PrismApp.kt` — warms CameraX up at process start.
  - `camera/PrismCamera.kt` — CameraX engine; all camera state for the UI (features.md "Camera").
  - `camera/Gallery.kt` — MediaStore names / folders, latest item, thumbnails.
  - `ui/CameraScreen.kt` — the camera screen (layout, gestures, focus ring, zoom pills, timer).
  - `ui/MenuSheet.kt` — "…" menu (shell). `ui/PermissionScreen.kt` — camera permission.
  - `effects/GlFx.kt` — GPU pipeline (SurfaceProcessor): looks, background blur / replace, overlay texture, analysis read-back.
  - `effects/Looks.kt`, `effects/Scene.kt`, `effects/FaceStickers.kt`, `effects/PhotoFx.kt` — looks, text / stickers / frames, face stickers, CPU photo path.
  - `ai/Vision.kt` — MediaPipe segmenter / face landmarker / gesture recognizer.
  - `ui/FxSheet.kt`, `ui/AiTabs.kt`, `ui/SceneLayer.kt`, `ui/TextEditor.kt` — ✦ sheet, overlay sync + selection box, text editor.
  - `ui/PcLink.kt` — QR scan + WebView link to Prism Cam on the PC. `update/Updater.kt` — GitHub updater.
  - `ui/KitScreen.kt` — phase 0 screen showing every component (replaced by the camera in phase 1, kept as a dev screen).
- `app/src/main/res/font/` — IBM Plex Sans Thai 400/500/600/700 (OFL, `licenses/`).
- `tools/` — `env.sh`, `build.sh`, `i18n-audit.sh`, `icons-to-kotlin.mjs`.

## Studio compositor (2.0.0)
- `studio/Model.kt` (Compose-state document + `RLayer` immutable snapshot) → `studio/Pump.kt` (snapshots to the GL
  thread on every change, renders content bitmaps off the main thread, GIF / character frames, tells `Vision` which
  trackers are needed, tells `PrismCamera` whether the GPU pipeline is needed at all).
- `effects/GlFx.kt` on "prism-gl": camera OES → canvas FBO (canvas = upright output size, ≤ 1920) → each layer as a
  textured quad (2D or OES program, SDF mask / border, shadow pass, colour matrix, chroma key, blend) → output pass
  per CameraX output (preview, encoder) mapping buffer → canvas (mirrored for the front camera; PreviewView mirrors it
  back). Face paint = mesh draw (468 points, canonical UVs from `assets/face_mesh.txt`, back-facing triangles skipped).
  Hand / face glow = capsule program. Photo pass = same compose with the still as the camera texture.
- Spaces: camera space (upright, unmirrored, 0..1) for the AI and tracking; canvas px (x right, y down) for layers;
  `Geometry.camToCanvas` maps one to the other through the camera layer (place, crop, flip, front mirror).

## Camera + effect pipeline
CameraX (Preview / VideoCapture → `PrismEffect` SurfaceProcessor, only while effects are on) → OES texture → GL thread: effects + overlays + small blurred copy
(for glass controls) → screen surface + MediaCodec input surface (recording) at the same time. ImageCapture in
zero-shutter-lag mode for photos, effects re-applied at full resolution off the UI thread. AI (phase 4) reads a
small copy at 15–30 fps.
